# KONFOR Website
Pages: index.html, bedding.html, home.html, office.html, contact.html
Folders: css/ js/ images/ (WebP) pdf/ (catalogues) - keep this structure.

VS Code: open the folder > Live Server > "Open with Live Server" (use Live Server, do not double-click the file).
GitHub: git init && git add . && git commit -m "KONFOR" && git branch -M main
git remote add origin https://github.com/USERNAME/konfor-site.git && git push -u origin main
Then Settings > Pages > Deploy from branch > main / root.

Edit products: js/data.js (n name, d [ar,en,tr,fr] descriptions, z sizes). Interface translations: js/i18n.js.
WhatsApp number: search 963991310740 in js/app.js and contact.html. Hero video: src in index.html.
